# GLAECIER – homepage prototype

Local prototype of a redesigned glaecier.com homepage. Next.js 16 (App Router), TypeScript, Tailwind CSS 4.
Booking, member login, membership sign-up and FAQ link to GLAECIER's official systems (glaecier.com and Flexybox); all destinations live in `src/content/links.ts`. This site never handles bookings, payments or accounts itself.

## Run it

```bash
npm install
npm run media   # only needed when /assets/images changes (already run once)
npm run dev     # http://localhost:3000 → redirects to /da  (English: /en)
```

Checks: `npm run lint`, `npm run typecheck`, `npm run build` (then `npm start` to serve the production build).

Screenshot views: desktop 1440×900 and mobile 375×812. The inline desktop nav appears from 1280 px; below that the “Menu” button opens a full-screen dialog.

**Heroes:** production shows `heroVariant` from `src/content/site.ts` – currently the video hero, with the approved image Hero B kept as fallback (`"b"`). In `npm run dev` a DEV switcher (bottom-right) compares Video, B and A; `?hero=video|b|a` links to one.

**Video hero:** the only footage is a 464×832 portrait clip (`assets/videos/glaecier-hero-original.mp4`, local only). `public/media/hero-video.mp4` is a silent H.264 re-encode at the same size (≈0.5 MB) with the first frame as poster. Portrait screens show it full-bleed; landscape screens show it sharp in a framed panel over a blurred copy, so it is never stretched. It only plays while on screen, and not at all under reduced motion or data saving (the poster stays). The word “quietude” is part of the footage.

## Preview deployment (GitHub Pages)

Preview URL: https://sebastianbf1.github.io/glaecier-website/ (noindex; separate from glaecier.com).

- The site is a static export (`output: "export"` → `out/`). `PAGES_BASE_PATH=/glaecier-website` prefixes every route and asset; `NEXT_PUBLIC_SITE_URL` sets canonical/hreflang/Open Graph URLs. Both are set by the workflow; local dev uses neither.
- Images: no runtime optimizer on a static host, so `npm run media` pre-generates WebP sizes (320/640/1080/1600 px) next to each 2560 px JPEG, and `src/lib/image-loader.ts` picks the right one.
- `public/index.html` sends `/glaecier-website/` to `da/`; `/da/` and `/en/` are real pages (`trailingSlash: true`).
- `.github/workflows/deploy-preview.yml` runs typecheck, lint and build, then deploys – **only on pushes to the `preview` branch** (or a manual run).
- Branches: day-to-day work on `main`; fast-forward `preview` to `main` when an update is approved.
- `assets/images/` (1.2 GB originals) is git-ignored. Keep the originals backed up elsewhere; `npm run media` needs them to add new photos.
- Only photos cleared for publication are committed: `.gitignore` allow-lists them in `public/media/`. All supplied photos are approved for publication; the unused ones and the dev-only Hero A photo stay local. `npm run check:export` (also run by the workflow) fails if the site references a photo that isn't in the export.
- `docs/` (asset manifest, content audit, screenshots) is local only.

Test the export locally under the same base path:

```bash
PAGES_BASE_PATH=/glaecier-website NEXT_PUBLIC_SITE_URL=https://sebastianbf1.github.io/glaecier-website/ npm run build
```

then serve `out/` at `/glaecier-website/` with any static server.

## Structure

```
assets/                 originals (not served)
  images/               68 files from Content.zip
  branding/             wordmark PNG from glaecier.com
  videos/               empty – none supplied
public/
  media/                web-sized copies, generated by scripts/prepare-media.mjs
  brand/                web wordmark (used as a CSS mask)
scripts/prepare-media.mjs   resize + inventory + duplicate detection
src/
  app/[lang]/layout.tsx  html shell, fonts, SEO metadata, hreflang, noindex
  app/[lang]/page.tsx    homepage: assembles the sections
  app/globals.css        design tokens (colour, type), reduced-motion-aware motion
  content/
    dictionaries/da.ts   Danish copy (source of truth, with VERIFIED/DRAFT/UNVERIFIED markers)
    dictionaries/en.ts   English copy (typed against da.ts)
    media.ts             which photo goes where, alt text, focal points
    media-inventory.json generated: dimensions, orientation, duplicate groups
    site.ts              address, email, hours, Instagram
  components/
    layout/              SiteHeader (incl. accessible menu dialog), SiteFooter
    sections/            Hero, Intro, Facilities, Experiences, Membership, Locations, PrivateHire, Philosophy
    ui/                  Photo, Wordmark, SectionIntro, buttons (ExternalAction)
docs/
  asset-manifest.md      every image: size, orientation, duplicates, use, crop, notes
  content-audit.md       verified vs draft content, items to confirm
```

- Change copy → `src/content/dictionaries/*`. Change a photo → `src/content/media.ts`. Components contain no copy or file names.
- Add a language → add it to `src/i18n/config.ts` and create a dictionary typed as `Dictionary`.

## Design notes

- Warm neutrals (paper, sand, wood) with charcoal and one deep harbour blue; every text/background token pair measures ≥ 5:1 (WCAG AA). Hero text sits on a photo with a soft scrim – re-check if the hero image changes.
- Newsreader (light) for editorial headings, Manrope (current site font) for UI and body.
- The real wordmark is used in header, hero and footer.
- Motion: a slow settle on the hero photo and gentle scroll reveals (CSS scroll timelines, no JS). Both are off under `prefers-reduced-motion`, and content is fully visible without them.
- Hero uses art direction: landscape harbour view on desktop, portrait pool view on phones.
